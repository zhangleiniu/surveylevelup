# Structure

The map of this repository: what is read-only evidence, what is writable output,
and how things are named.

**Does not hold:** anything that changes weekly. Current state lives in
`CLAUDE.md`.

---

```
{{PROJECT_DIR}}/
├── CLAUDE.md              index, current state, hard rules      [writable]
├── CONSTITUTION.md        enduring standards, living            [writable]
├── DECISIONS.md           dated decisions, append-only          [append-only]
├── FINDINGS.md            cross-paper findings                  [writable]
├── PROVENANCE.md          artifact lineage                      [writable]
├── STRUCTURE.md           this file                             [writable]
│
├── corpus/            →   {{CORPUS_PATH}}                       [READ-ONLY, symlink]
│   ├── TOPIC.md           the corpus overview
│   ├── <category>/        PDFs, arranged by the reading taxonomy
│   └── .paperlevelup/     papers.jsonl and friends — owned by paperlevelup
│
├── inputs/                                                      [READ-ONLY once written]
│   ├── references.bib     generated by build_bib.py
│   ├── fulltext/          <bibkey>.md, generated by extract_fulltext.py
│   ├── prompts/           <type>_card.md — the extraction contracts
│   └── cards/<type>/      <bibkey>.md — one card per paper per applicable type
│
├── state/                                                       [written by scripts]
│   ├── progress.json      gate state, signatures, trial papers, counts
│   ├── friction.md        feedback to the skill, not about this survey  [append-only]
│   └── stances.jsonl      optional; contested citation pairs only
│
├── drafts/v1/                                                   [writable]
│   ├── main.tex
│   ├── sections/          one file per section
│   ├── appendices/        one file per appendix
│   └── figures/
│
└── archive/               superseded documents                  [write-once]
```

## Naming

- **The bib key is the canonical ID.** Per-paper files are `<bibkey>.md` with no
  numeric prefix, in every directory that holds one.
- Prompts are named for what they extract: `method_card.md`, `benchmark_card.md`.
  Not `P1`, not a version number in the filename — versions go in `PROVENANCE.md`.
- Section files are named for the section. LaTeX `\label` IDs, once assigned, are
  never renamed.
- `\appendix` is declared exactly once.

## Read-only means read-only

`corpus/` and `inputs/` are evidence. A problem in them is fixed at the producer
and re-run:

| Wrong thing | Fix by |
|---|---|
| Paper metadata | correcting it in the corpus sidecar via `paperlevelup`, then re-running `build_bib.py` |
| A bib entry | the same — never by editing `references.bib` |
| Full text | re-running `extract_fulltext.py` |
| A card | flagging it in `PROVENANCE.md`, then re-running its prompt |
| A card schema | revising the prompt, recording the change in `PROVENANCE.md`, re-running affected cards |

## Superseded documents

They move to `archive/` with a dated name. They do not stay in the root with a
warning label attached, because that is the same fact living in two places —
which is the failure this whole scheme exists to prevent.
